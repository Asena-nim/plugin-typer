Photopea'ya yükleme

  1. Repo içinde Settings → Pages bölümünü açın.
  2. Deploy from a branch seçin.
  3. Branch: main ve Folder: /(root) seçip Save tıklayın.
  4. Yayın tamamlanınca şu adresi kontrol edin: https://asena-nim.github.io/plugin-typer/
  5. Photopea'da Window → Plugins bölümünden eklenti ekleme/yönetme ekranını açın.
  6. İstenen URL alanına önce https://asena-nim.github.io/plugin-typer/plugin.html adresini girin. Photopea klasör URL'si istiyorsa kök adresi kullanın.
Önemli: GitHub Pages ve Photopea için HTTPS kullanın. GitHub Pages ilk yayınlanırken birkaç dakika beklemek gerekebilir. Eski sürüm görünürse eklentiyi kapatıp yeniden açın ve tarayıcı önbelleğini yenileyin.

Kullanım

  1. Metin alanına scripti yapıştırın.
  2. Listeden bir satır seçin.
  3. Stil seçin veya düzenleyin.
  4. Tekli yerleşim için Sırayla Tek Tek Yerleştir düğmesini kullanın.
  5. Birden fazla metin için toplu seçim yapıp Toplu Metin Yerleşimi düğmesine basın.
  6. Fontun Photopea oturumunda mevcut olması gerekir; eklenti font kurmaz.

Sorun giderme

Eklenti görünmüyor: Pages'in main ve /(root) için etkin olduğunu, adresin HTTPS olduğunu kontrol edin.

Eski sürüm açılıyor: Pages dağıtımını bekleyin, Photopea eklenti penceresini kapatıp yeniden açın.

Font uygulanmıyor: Photopea'daki gerçek font adını kullanın ve fontu Photopea oturumuna ayrıca yükleyin.

Logo/desen aktarılmıyor: Dosyayı tekrar ekleyin. PDF önizlemesi ve gelişmiş clipping/warp işlemleri Photopea sürümüne göre sınırlı olabilir.

Veriler kayboluyor: IndexedDB cihaz/tarayıcıya özeldir; ayar JSON'unu düzenli dışa aktarın.
