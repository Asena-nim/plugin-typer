Typer for Photopea

Manhwa ve manga metinlerini stillerle Photopea'ya yerleştirmek için Türkçe eklenti.

Photopea'yı Aç GitHub Repo

Özellikler

Metin yerleşimi

Sırayla tek tek veya seçilen metinleri toplu olarak yerleştirme.

Stiller

Font, boyut, satır aralığı, önek, metin rengi ve kontur rengi.

Font arama

Kayıtlı fontlar arasında arama yapıp seçtiğiniz fontu stile aktarma.

Logo ve desen

Görselleri geçici olarak saklama, stile bağlama ve yöneticiden seçme.

Efektler

Opaklık, gölge, bulanıklık, dalga, warp, bükme ve degrade ayarları.

Yedekleme

Stilleri, font listesini ve ayarları JSON olarak dışa/içe aktarma.

Photopea'ya yükleme

  1. Önce Asena-nim/plugin-typer reposunu açın.
  2. Repo içinde Settings → Pages bölümüne gidin.
  3. Build and deployment altında Deploy from a branch seçin.
  4. Branch olarak main, klasör olarak /(root) seçin ve Save düğmesine basın.
  5. GitHub Pages adresiniz şu biçimde olur:
    https://asena-nim.github.io/plugin-typer/
  6. Photopea'yı açın. Window → Plugins paneline girin ve Add / Add Plugin seçeneğini kullanın.
  7. Eklentinin GitHub Pages adresini URL olarak girin. Eğer Photopea sürümünüz URL eklemeyi desteklemiyorsa aşağıdaki yapılandırma JSON'unu kullanın.
Not: GitHub Pages yayınlandıktan sonra ilk açılışta birkaç dakika gecikme olabilir. Photopea'da eski sürüm görünürse eklenti penceresini kapatıp tekrar açın veya sayfayı yenileyin.

Photopea yapılandırma JSON'u

Aşağıdaki JSON'daki URL'yi kendi Pages adresinizle aynı olacak şekilde kullanın:

{
  "environment": {
    "plugins": [
      {
        "name": "Typer for Photopea",
        "url": "https://asena-nim.github.io/plugin-typer/",
        "width": 420,
        "height": 720
      }
    ]
  }
}

Bazı Photopea sürümlerinde eklenti ekleme ekranı JSON dosyası yerine doğrudan URL isteyebilir. Bu durumda yalnızca Pages URL'sini kullanın.

Kullanım

  1. Metin alanına scripti yapıştırın.
  2. Listeden bir satıra dokunarak seçin.
  3. Stil kartlarından birini seçin.
  4. Seçili alan varsa metin o alanın merkezine, yoksa belgenin merkezine yerleştirilir.
  5. Birden fazla satır için satır seçim/toplu yerleşim akışını kullanın.
  6. Font Photopea'da yüklü değilse Photopea varsayılan fonta geçebilir; fontun Photopea içinde ayrıca mevcut olması gerekir.

Sorun giderme

Eklenti listede görünmüyor: Pages ayarının main ve /(root) için etkin olduğunu, URL'nin HTTPS ile açıldığını kontrol edin.

Eski sürüm açılıyor: GitHub Pages dağıtımının tamamlanmasını bekleyin; ardından Photopea'yı ve eklenti panelini yeniden açın.

Font uygulanmıyor: Eklentideki isim, Photopea'nın gerçek font adıyla eşleşmeli ve font Photopea oturumunda yüklenmiş olmalıdır.

Logo/desen görünmüyor: Dosyayı eklenti yöneticisine tekrar ekleyin ve stile doğru türde bağlandığını kontrol edin. PDF önizlemesi tarayıcıya ve Photopea aktarımına bağlı olabilir; PNG/JPG/WebP daha güvenilir formattır.

Veriler kayboldu: Tarayıcı site verilerini temizlemeyin. Stilleri ve ayarları düzenli olarak JSON dışa aktarın. IndexedDB kayıtları cihaz/tarayıcıya özeldir.
